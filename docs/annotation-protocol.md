# 标注协议（Annotation Protocol）

本文件是鼠标点击 ground-truth 标注的**唯一权威口径**。`snap_v2` 吸附规则的参数只在本文件第 3 节定义一次，其余文档（`README.md`、`labels/README.md`）只引用、不复制。

> **冻结约束（`snap_v2` 自 2026-06-12 冻结）：** 改动第 3 节任一参数 = 全部录音重新标注。改动须升版本号（`snap_v2 → snap_v3`）并在第 3 节"版本记录"中记录变更。

---

## 1. 事件语义（Event Semantics）

- **原子事件 = 一次物理点击**，以其 **down（按下）onset 为代表**。
- **切点 = down onset 样本。** 这是流水线最终要对齐的目标，也是评估唯一计分的对象。
- 一次物理点击含 **down（按下）+ up（抬起）两个瞬态，相隔约 60–150 ms**。
  - **down = 这对里的第一个瞬态**，通常更尖、更响（press）。
  - **up = 第二个瞬态**，通常更弱（release）。
- **up 不是切点、不是独立目标事件**，仅作次要标注，供 verify 阶段做"配对核验"。

---

## 2. onset 参考点 = **主瞬态**的能量起跳点（不是峰值，也不是前导子瞬态）

在 2–5 ms 的尖锐瞬态上，"onset 落在哪一个样本"本质是**约定**而非客观事实。本项目把这个约定定为：

> **onset = 主瞬态（main transient，窗内最响的那个）能量起跳的第一个样本（"脚点"），而非峰值。**

**precursor 语义（snap_v2 起明确）：** 本数据中多数真实点击带有一个**前导子瞬态**（precursor，约在主峰前 15–25 ms，已在原始宽带能量中证实为真实声学能量、非滤波伪影）。**precursor 不算 onset**——切点语义是"切在主点击"，onset 相对主峰回退求得；明显弱于主峰的前导能量被规则自然排除（见第 3 节）。

理由：切点口径 = 参考点口径 = 评估目标，三者完全一致——评估直接衡量最终要切的那个点。

**人不直接抠样本。** 人只做"这里恰好有一次点击"的判断 + 粗略放置标记（**落在瞬态 ±20 ms 内即可**，无须 1 ms 精度）；精确到样本由第 3 节的**确定性吸附规则**统一完成。这样 ~2500 次点击的一致性才有保证，避免跨标注者抖动污染误差分布。

---

## 3. 吸附规则 `snap_v2`（已冻结 2026-06-12，唯一真源）

把人工确认的粗标记吸附到精确 onset 样本的确定性规则。核心思想：**人保证"每个标记 ↔ 恰好一次点击"这个先验；规则在标记邻域内取最强峰、再从峰值相对回退到脚点**——不依赖绝对本底，密集段与 precursor 都不构成干扰。

| 项 | 取值 |
| --- | --- |
| 输入 | `data/wav/<name>.wav`（48 kHz / mono / float32）＋ 人工确认的标记列表（每个真实瞬态恰好一个标记，落在瞬态 ±20 ms 内） |
| 高通 | Butterworth 4 阶，截止 **2000 Hz**，零相位 `filtfilt`（零相位＝无群延迟；对称前向涂抹见"已知偏置"） |
| 包络 | **1 ms 窗（48 样本）** 的 RMS 包络（对高通后信号；与 §5.1 同一唯一真源） |
| 搜索窗（自动钳位，互不重叠） | `W = [max(mark − 30 ms, mid_prev), min(mark + 30 ms, mid_next)]`，`mid_*` = 与**相邻标记**（不分 down/up）的中点。钳位保证每窗只含本标记的瞬态；±30 ms < down→up 最小间隔 60 ms，故未标注的 up 不会闯入本窗。 |
| 主峰定位 | `peak = W 内包络最大值的样本`。precursor / 残余干扰弱于主峰，argmax 自然选中主瞬态。 |
| onset 回退（自适应中点） | 取回退区 `B = [peak − 15 ms, peak]`：`m = B 内包络最小值`，`R = 20·log10(amp(peak)/amp(m))`（峰前动态范围，dB）；**回退深度 `D = min(0.5·R, 20 dB)`**，`thr = amp(peak) × 10^(−D/20)`。从 `peak` 向左找**最近的 `env < thr` 样本 `j`**；`onset = j + 1`（最靠近主峰的一次上穿）。因 `amp(m) < thr ≤ amp(peak)`，**上穿必然存在，无 fallback 分支**。precursor 与主峰间的低谷低于 dB 中点，回退停在主升沿脚点、不会爬到 precursor。 |
| 存疑判据（突出度） | `R < 12 dB` → 标 `confidence=存疑`（弱瞬态 / 紧贴前一瞬态拖尾 / 疑似噪声候选），交人工复核。存疑率随 §3.1 一并报告。**为何自适应：** 本数据峰前 15 ms 动态范围中位仅 ~16 dB（p25 ~11.5 dB），固定回退深度要么够不到（深）、要么骑在噪声上（浅）；dB 中点对动态范围自适应且必有解。 |

> **已知偏置（随版本串声明）：** `filtfilt` 前向涂抹 + 居中 RMS 窗使包络在真实起跳前微微抬升，回退所得 onset 相对真实起跳**系统性略偏早**（量级 ≲1 ms）。作为统一约定接受（GT 与切割同口径），纳入 §3.1 的口径不确定度报告。

**版本串（随结果一并报告）：** `snap_v2: HP2k / env1ms-RMS / win±30ms-clamp / peak-argmax / bt15ms-mid0.5-cap20dB / prom>=12dB`

### 版本记录

## 4. CSV 标注格式

- **每个 WAV 一个文件：** `labels/<wav_basename>.csv`，与 `data/wav/<name>.wav` 同名配对（如 `labels/BJ_C1.csv` ↔ `data/wav/BJ_C1.wav`）。
- **坐标系 = 解码后 WAV 的样本帧，不是 m4a。**（m4a 有 priming delay；标注、检测、切割都在同一份 WAV 上做，坐标才一致。）
- 含表头，UTF-8，按 `sample` 升序。

```
sample,time_s,type,confidence
12345,0.257188,down,确定
19632,0.409000,up,存疑
```

| 列 | 类型 | 说明 |
| --- | --- | --- |
| `sample` | int | WAV 样本索引 @48 kHz——**真源**（整数无舍入） |
| `time_s` | float（6 位小数） | `= sample / 48000`，给 `mir_eval` 用 |
| `type` | `down` \| `up` | 瞬态类型 |
| `confidence` | `确定` \| `存疑` | 标注把握度 |

## 5. down / up 指派与边界规则

- 一对点击 = 相隔 **60–150 ms** 的两个瞬态：通常**第一个 = down（更尖更响），第二个 = up（更弱）**。密集 / 双击序列下的指派以 §5.1 的确定性规则为准。
- **up 尽力而为：** 仅在能清晰辨认时标；不确定标 `存疑`；看不见就**留空不标**。
- **7–10 ms 周期性脉冲串 = 环境干扰，绝不标注。** 标注时显式排除该区段（量化结果见 `src/interference_analysis.py`：`IntlSB20` 最重，约占 8% 时长）。
- **点击间距：** click-to-click（down→down）`min_gap` 约 30–50 ms 安全。注意一对内 down→up 仅相隔 60–150 ms——峰拾取的 `min_gap` 不可大到把同一对的 down/up 误并（属 step 4 峰拾取的设计注记，与标注无关，此处仅备忘）。

### 5.1 密集 / 双击序列的 down/up 指派（确定性后处理 + 人工复核）

双击序列 `down₁–up₁–down₂–up₂` 中，`up₁→down₂` 的间隔也可能落在 60–150 ms，"第一个=down、第二个=up"会把 `down₂` 错配成 `up₁`。改用如下确定性规则：

- 输入：按时间排序的瞬态（onset 样本 + 峰值包络幅度）。**峰值包络幅度 = `snap_v2` 的 HP2k / 1ms-RMS 包络**（与第 3 节同一定义，唯一真源；幅度即在瞬态峰值样本处读取该 RMS 包络，dB 比较按 `20·log10` 幅度域）。
- **贪心从左到右**，维护一个"待配对 down"：对每个瞬态 `T`，记其比待配对 `down D` 弱的量 `ΔdB = 20·log10(amp(D)/amp(T))`（正值＝更弱；`amp` ＝上方 HP2k / 1ms-RMS 包络在峰值样本处的幅度）。当存在待配对 `D` 且 `(T − D) ∈ [60, 150] ms` 时，按三档确定性判定（margin 在 §3.1 于 `BJ_C3` 校准）：
  - `ΔdB ≥ 6`（明显弱）→ `T = up`（`确定`），与 `D` 配对并关闭 `D`。
  - `3 ≤ ΔdB < 6`（**存疑带**）→ `T = down`（`confidence=存疑`），开启新的待配对 down；`D` 保持无 up（允许）。**默认判 down 而非 up：** down 完整性是硬约束，假 down 可复核删除、易暴露；藏进 up 的漏标 down 隐蔽且污染评估。
  - `ΔdB < 3`（不够弱）→ `T = down`（`确定`），开启新的待配对 down。
  - 不存在待配对 `D`，或 `(T − D) ∉ [60, 150] ms` → `T = down`（`确定`），开启新的待配对 down。
- 含义：瞬态只有在**明显弱**（≥6 dB）时才判为前一个 down 的 up；否则一律判为新 down——`down₂`（响）不会被错配成 `up₁`。
- **存疑项复核手段：** 对标 `存疑` 的瞬态，看它自己后续 `[60, 150] ms` 内有没有一个更弱的 up——若有，则它几乎肯定是 `down`（一对点击的按下端），可据此确认。
- 该指派为**确定性后处理**（并入后续 label-finalize 工具），人工只复核存疑项，与"人只确认、规则定位"一致。

## 6. verify 阶段的配对核验（设计注记）

- 对每个 down，向后 **60–150 ms** 找 up：**找到加分、找不到不扣分。** up 缺失绝不否决 down，因此 up 标注的不完整不会污染评估。
- 先在 `BJ_C3` 上统计 up 的可辨率，再据此确定该规则在 verify 中的权重。

---

## 7. 标注工作流

1. 用粗检测（去重 + 最小间距合并后）导出候选 → 转成标注工具可导入的 label 文件作为**种子**。
2. **工具：** 默认 **Sonic Visualiser**（样本级缩放、CSV 导出）；更熟 Audacity 亦可——亚毫秒精度由 `snap_v2` 保证，工具差异不重要，选顺手的即可。
3. 人工逐个**确认 / 增删 / 粗调**。要求只有两条：**每个真实瞬态恰好一个标记**（计数先验，snap_v2 的窗口钳位依赖它）；标记落在瞬态 **±20 ms** 内即可，不必抠样本。
4. 跑 `snap_v2` 把每个标记吸附到精确样本，产出最终 `labels/<name>.csv`。
5. up 同法、尽力而为。

---

## 8. 评估口径联动

`mir_eval.onset` 对比 GT 与检测输出：

- 报告**误差分布**（中位数、p95，单位 ms）；
- 报告**紧容差下的 F-measure**（如 5 ms / 10 ms）；
- 一并报告第 3.1 节的**口径不确定度**与 `snap_v2` 版本串。
- **只有 `down` 行参与 onset 评估；`up` 仅供 verify 核验。**
